# UM982 RTK Framed Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carry UM982 commands, NMEA 0183, and RTCM bytes between Jetson USB CDC and STM32 USART6 without disrupting the existing application protocol.

**Architecture:** STM32 stores USART6 RX bytes in a fixed ring buffer and exposes framed write/read commands through the existing USB CDC protocol. Jetson provides a small binary-safe API and `stm32_rtk` CLI that fragments writes and polls reads.

**Tech Stack:** STM32F407 HAL C, Make, Python 3 standard library, ROS2 Python packaging, unittest.

## Global Constraints

- USART6 remains PC6 TX, PC7 RX, `115200 8N1`, no flow control.
- Preserve the existing 32-byte application payload limit.
- Carry arbitrary bytes unchanged; do not parse NMEA or RTCM.
- Keep USB CDC request/response driven; do not send unsolicited frames.
- Add no dependencies and no DMA.
