# WS2812B RGB Control Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 通过 PB13 驱动三颗级联 WS2812B，并在 Qt 上位机中提供预置色、自定义色、亮度、闪烁和可配置状态回读。

**Architecture:** STM32 新增一个独立 RGB 模块，用 DWT 周期计数生成单像素 GRB 时序，并由现有 TIM6 软件节拍推进闪烁状态。现有二进制协议、Python `SerialHost`、Qt Worker 和 QSettings 依次扩展，不新增 ROS 接口、第三方依赖或单灯寻址抽象。

**Tech Stack:** STM32F407 HAL/Cortex-M4 DWT、C11、Python 3、PySide6 Widgets、unittest、GNU Arm Embedded Toolchain

## Global Constraints

- 三颗 WS2812B 按 DIN 到 DOUT 级联，始终同步同色，连续发送三组相同的 24 位 GRB。
- RGB 数据引脚固定为 PB13；PE7 `SIGNAL_LED` 普通 GPIO 保持不变。
- 默认状态固定为绿色 `#00FF00`、25% 亮度、慢闪 1 Hz、初始亮相位。
- 模式固定为关闭、常亮、1 Hz、2 Hz、标称 4 Hz；闪烁占空比固定 50%。
- RGB 状态只保存在 RAM，复位恢复默认值，不写 Flash。
- 协议帧固定为 `0x0C/0x8C` 设置和 `0x0D/0x8D` 查询。
- Qt 提供基础 8 色、马卡龙 8 色和系统颜色选择器；只在点击“应用”时发送。
- RGB 回读开关位于 RGB 页面，频率位于控制页，默认开启、2 Hz，并使用 QSettings 保存。
- 不新增依赖、ROS 2 topic/service、RGB CLI、主题框架或灯珠数量配置。
- PB13 的 800 kHz 时序和 3.3 V 数据电平必须保留实机示波器验收项。

```c
typedef enum {
  APP_RGB_LED_MODE_OFF = 0U,
  APP_RGB_LED_MODE_STEADY = 1U,
  APP_RGB_LED_MODE_SLOW_BLINK = 2U,
  APP_RGB_LED_MODE_MEDIUM_BLINK = 3U,

                       uint8_t brightness, App_RgbLedMode mode);

```

Implement `app_rgb_led.c` with one static state, integer brightness scaling `(value * brightness + 50U) / 100U`, GRB byte order, and a DWT deadline loop. Preserve PRIMASK around the 24-bit send:

```c
primask = __get_PRIMASK();
__disable_irq();
App_RgbLed_SendByte(green);
App_RgbLed_SendByte(red);
App_RgbLed_SendByte(blue);
RGB_GPIO_Port->BSRR = (uint32_t)RGB_Pin << 16U;
if (primask == 0U) { __enable_irq(); }
```

Use 2 ms tick half-periods `250U`, `125U`, and `63U`; only transmit when applying a setting or toggling a phase. `App_RgbLed_Set()` validates all parameters before changing any state and starts every accepted mode in the bright phase, except OFF.

## Hardware Acceptance (not automatable)

After software verification, use the real board to measure PB13 and check: 800 kHz nominal bit period, distinct 0/1 high widths, reset low time of at least 100 us, three lamps changing synchronously, all 16 presets, 0/25/100% brightness, all five modes, RGB readback enable/disable, and sustained USB CDC operation. If data high level or waveform margin is unreliable, stop software tuning and add the documented 74AHCT/74HCT level shifter.
